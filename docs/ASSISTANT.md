## Sprint 9.3 语气与额度

- 统一提示以当前消息和最近对话共同判断气氛。好消息、主动玩笑可以自然接梗。谈到烦恼时收敛，话题转轻后恢复灵活。对语气的纠正只在相关上下文内持续，不把一次不满当成永久偏好。仍使用最多两轮同一接收方的已完成回复，不新增情绪关键词、固定话术或对话持久化。
- 旧窗口把本站所有本地和 AI 聊天按 IP 合计，每 10 分钟仅 8 次。旧预算按请求固定保留 0.01/0.02 美元，默认 0.10 美元分别只够约 10 次普通或 5 次复杂请求。失败、取消也占全部预留。代码能复现这些限制，历史用户请求的具体错误码未取得。
- 外部模型请求优先使用经服务器会话验证的账户身份。访客使用本站签发的 HttpOnly 会话 Cookie。每 10 分钟每账户 24 次、每访客 12 次、同一 IP 总计 60 次。这些窗口从首次请求开始。IP 保底限制用于约束新访客标识的快速轮换。本地模式走独立的每 IP 120 次窗口，不占外部额度。账户标识和 Cookie 不发送给模型。
- 站点和供应商每日请求数与预算仍分别配置，默认各 120 次、0.10 美元。外部请求全局最多 8 并发，每个供应商最多 4。按当前模型输入 UTF-8 字节估算、输出上限和公开未缓存高峰价预留，获得供应商用量后按上报 Token 结算。未知 OpenAI 型号使用较高的内部占位价，启用其他模型前需复核。费用是应用估算，生产仍应设置供应商财务上限。
- 真正尝试外部调用才占一次每日请求次数。明确的上游认证、余额、模型不可用或限流拒绝释放费用预留。无法得知实际用量的取消、超时或中途断开只保留本次预留。手动重试算新请求，无自动重试。每日计数 UTC 00:00 重置，按进程维护。`Retry-After` 只用于有确定等待时间的窗口、每日次数和供应商明确返回的等待时间。并发与预算不足不提供假倒计时。本地入口不受 AI 冷却阻挡。

## Sprint 9.2 语气规则与真实验证

## Sprint 9 统一供应商标准

- `assistant/routes.ts` 负责访客限流、选择用户明确授权的供应商和模型、最小上下文、预算、超时及回退。`grounded.ts` 提供每个供应商共用的产品指令和结构化校验。OpenAI 原先的固定开场和结尾选择已迁入统一的生成与校验路径。
- 共用标准要求先理解整句话、关注语气和话题变化、用合理推测辅助理解、按复杂度调整表达。涉及第三方的动机保持不确定。审核证据由本次检索提供，引用 ID 和摘要由服务端核对及插入。未经验证的响应和内部推理不会进入聊天。站内声音或练习仍需用户确认。
- 用户选中并授权的供应商和模型必须与后端注册表一致。可发送本次输入及最多两轮相邻、已完成、同一接收方的 AI 对话。前端切换供应商时取消在途请求并清除授权。站内校验先拦截敏感输入，助手没有日记或账户数据访问接口。
- AI 请求必须包含 `mode: "ai"`、`provider` 和与状态接口一致的 `model`。旧式 `useModel` 请求或模型不匹配时返回标记为本地回退的回复。
- DeepSeek 仍优先。历史已通过本机验收的 `deepseek-flash` 默认配置为已审核，管理员可设置空值隐藏；模型变化时 `AI_VERIFIED_DEEPSEEK_MODEL` 必须匹配 `DEEPSEEK_MODEL`。OpenAI 必须同时配置 `AI_OPENAI_API_KEY`、`AI_OPENAI_MODEL` 和经独立验收后填写的 `AI_VERIFIED_OPENAI_MODEL`。两个验收字段都属于维护者配置声明，服务不会后台发送探测或自动消费额度。供应商可用性以当前请求结果为准。
- `DEEPSEEK_BASE_URL` 与 `AI_OPENAI_BASE_URL` 只接受各自白名单内的官方 HTTPS 地址，适配器再次验证，禁用重定向。请求正文不能传地址、密钥、预算或外部工具。Gemini 和其他接口可通过新增适配器与服务端白名单扩展，当前 UI 不展示。
- 普通请求两个适配器都限制 192 输出 Token 和 12 秒。输入达到 90 字符、已带一轮对话且本次达到 40 字符、或命中多份证据时提高预算，DeepSeek 启用低档思考且最多 1024 Token，OpenAI 最多 768 Token，使用各自适配参数。复杂请求超时 25 秒，前端总等待 30 秒。DeepSeek 的思考字段仅由服务器接收并丢弃。应用收齐并校验结构化 JSON 后按段写入 NDJSON，取消会传给上游。 [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) · [OpenAI Chat Completions](https://platform.openai.com/docs/api-reference/chat/create)

## 交互状态与限流

页面的当前模式统一为 `ai` 或 `local`，请求显式携带该模式。消息标签来自响应帧或请求错误。改用本地知识先切换模式、取消旧请求，再按本地路径重发当前问题。重试沿用当前模式。

DeepSeek 闲聊用校验过的简短文字回复。明确知识问题才检索审核引用，用户主动表达需求时才产生建议。旧格式仅给出澄清意图、没有答复文字时，服务端提供按输入区分的本地回退，并标记来源。深层安全分流仍先于模型调用。

站内 IP 限流、模型并发和每日用量分别返回原因。DeepSeek 429 为上游速率限制，402 为余额不足。已知上游错误回传安全分类及可用的 `Retry-After`，前端等待期间禁止相应重试。来源不明的 429 显示通用限流信息。旧版的「模型额度暂不可用」对应本站的 `MODEL_LIMIT`，同一个码曾用于并发、每日请求数和预留预算。

## Sprint 6C 意图理解与证据回答

DeepSeek 复用同一 SSE 请求，先接收本地检索的最多两条审核摘要和局限，以及用户本次输入。输出由四种结构组成，分别是证据回答、已审核功能建议、简短澄清和资料不足。模型可以理解未命中关键词的表达。管理员可继续使用 OpenAI 的审核措辞模式。

证据回答由模型编写贴合问题的短说明并指定一个证据位置。服务端要求该位置出现恰好一次，要求引用 ID 来自本次检索，再插入原审核摘要。前端显示该条来源及局限。自由说明仅接受短篇、无链接、数值和高风险措辞的内容。筛查是保守规则，无法证明所有自然语言说明的语义正确性，科学事实应以审核摘要和原来源为准。

所有推荐都通过共享的审核清单映射到已有的睡前状态、声音场景或练习，并由服务端补充理由。证据回答中的附带推荐还需要与本地规则一致。前端保留确认和手动启动。隐私及医疗分流先于模型调用，聊天仍只留在页面内存。结构或证据引用无效时回退到有本地标识的回复。网络异常保留重试和本地入口。

DeepSeek 新模式最多生成 192 个输出 Token，回复在服务端完整校验后才通过现有响应流发送。模型输入仍只含本次用户输入、固定指令和本次审核摘要及局限。沿用 0.01 美元的保守单次预留及现有限流。实际模型效果和费用需另行授权验证。

## 流程与边界

- `GET /api/assistant/status` 返回已开放供应商、模型名和知识库版本。`POST /api/assistant/chat` 校验 Origin、JSON、字段和长度，输出 NDJSON 流。前端不附带登录 Cookie，提供停止、重试、重新生成和本地回退。
- 规则层识别急症、医疗、隐私和越权内容，输出固定回应或匹配审核知识。遇到已识别的敏感内容、提示词注入和医疗问题时，不调用模型。关键词安全筛选可能漏判，因此请勿在聊天中粘贴私人正文或凭据。
- 模型适配器通过 SSE 收集结构化输出，服务端校验后发送回复。供应商无工具或数据库连接，引用直接来自版本化知识库。
- 确定性规则只允许现有雨夜、海岸、微风场景及四项成人放松练习。前端单独确认后才更新“今晚状态”并跳转；播放和练习启动仍由用户控制。
- 站内规则至多读取三条用户输入，长度各不超过 400 个 JavaScript 字符单元。限流、预算和并发按 Sprint 9.3 规则。进程重启会清空计数，多实例须由网关或供应商额度统筹。API 不自动重试。
- 测试仅使用模型替身和模拟 SSE。本轮真实供应商请求数为 0，未发生真实 API 调用费用。模型上线需另外验证密钥可用、模型兼容、代理流式转发和供应商预算。

## 知识库版本

`2026-11-20.1` 在初版六条内容上新增睡梦知识。按审核关键词检索，最多返回两条可追溯引用。同一关键词得分相同时采用登记顺序。记录含来源、发表或更新时间、适用人群、证据类型或强度及主要局限。更新知识时须复核来源、适用范围和证据局限，再递增版本。

| 主题                 | 来源及时间                                 | 局限                                                                                                                              |
| -------------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| 睡前安静时间、咖啡因 | NHLBI 健康睡眠习惯，2022-03-24 更新        | 一般健康建议，个体反应和适合的时间因人而异。 [原文](https://www.nhlbi.nih.gov/health/sleep-deprivation/healthy-sleep-habits)      |
| 白噪声与粉红噪声     | Capezuti 等系统综述，2022-06-01 刊期       | 研究差异较大，未得出改善睡眠的明确结论。 [全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9163611/)                                |
| 睡前待办整理         | Scullin 等随机比较，2018-01 刊期           | 年轻成人、单夜实验室研究，缺少无写作对照。 [全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5758411/)                              |
| 放松练习             | AASM 成人慢性失眠临床指南，2021-02-01 刊期 | 临床放松疗法的证据质量较低，不能为本应用短练习背书。 [全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7853203/)                    |
| 就医评估             | NHLBI 就医评估资料，2022-03-24 更新        | 供患者了解评估过程，不能据此自行诊断。 [原文](https://www.nhlbi.nih.gov/health/insomnia/diagnosis)                                |
| 睡梦与睡眠阶段       | Siclari 等实验室研究，2017-04-10           | REM 和非 REM 中均有梦报告。脑电与报告的相关性不能说明做梦的原因或功能。 [全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5462120/) |
