# 个人睡眠空间

登录后在「我的账户」新建、编辑、使用或删除账户声音场景。设备收藏与本地预设通过「复制到表单」导入，确认保存才上传。遇到同名冲突时保留原场景，可改名另存。访客声音播放和设备数据独立运作。

账户默认设置包含内置或账户场景、音量和定时分钟数。登录时播放器空闲且设置已保存才应用，由用户手动开始播放。设置可手动应用和清除。退出或切换账号时停止账户混音，恢复设备配置并清空私人视图数据。

日记可以只记录一项，每个账户每个所选日期仅一条。跨午夜请填写事件的实际日期。事件存 UTC，所属日期和 IANA 时区保留。夏令时不存在的本地时间要求重新填写，重复时刻可选第一次或第二次。7 天和 30 天趋势截至查询结束日期，作息使用记录时区及相对日期，日期缺口不连线。图表附同源数据表。

## 接口

所有路径以 `/api/space` 为前缀。有效 Cookie 决定用户 ID，`X-JHaven-Account` 校验视图的预期账户。写请求校验 Origin 和 JSON，并限流。所有响应禁止缓存。

| 接口                                                       | 用途                      |
| ---------------------------------------------------------- | ------------------------- |
| `GET /`                                                    | 取当前用户预设和默认设置  |
| `POST /presets`、`PUT /presets/:id`、`DELETE /presets/:id` | 保存、修改、删除账户预设  |
| `PUT /preferences`、`DELETE /preferences`                  | 保存、清除默认设置        |
| `GET /diary?from=YYYY-MM-DD&to=YYYY-MM-DD`                 | 查询最多 366 天的私人记录 |
| `POST /diary`、`PUT /diary/:id`、`DELETE /diary/:id`       | 新增、编辑、删除私人记录  |

他人资源和不存在的资源统一返回 404。重复名称或日期返回 409，字段无效返回 400。未登录返回 401。尚未迁移时个人空间返回 503，访客播放器仍可用。

## 正式库迁移交接

原有 001 和 002 文件不变。003–005 仅新增 `sound_presets`、`sleep_diaries`、`user_preferences` 和三条迁移记录。用 `node scripts/prepare-space-migration.mjs` 生成 `artifacts/sprint4-navicat.review.sql`。生成器不连接数据库。

先用 Navicat 管理员连接对目标 `jhaven` 单独执行脚本头部预检。确认两条历史记录的校验和正确、总历史数为 2、新表数为 0，再按顺序分块执行，开启遇错停止。DDL 可能隐式提交，部分成功时先检查实际表结构与登记情况。正式库仍待管理员执行，运行账号沿用已有数据库范围权限。

隔离环境使用以 `jhaven_test_` 开头的专用数据库。注入测试库配置后运行 `npm run db:migrate`、`npm run check` 和 `npm run test:e2e`。正式库迁移验收仅核对结构、迁移记录和 API 就绪。所有业务写入测试均在隔离库进行。
