# 设计系统

## 气质

Calm、Premium、Minimal、Atmospheric、Immersive、Gentle、Quiet。用深夜蓝和轻微暗紫层次、月光色与柔和灰白文字构建安静空间；品牌标语保持原文。

当前首页使用独立 CSS 月亮、山线与水面；雨夜、海岸、微风使用静态 CSS 插画。无远程大图、循环动画、闪烁、粒子或高饱和发光。轻微玻璃层次只用于导航和面板；模态背景采用 3px 模糊，不依赖大面积 GPU 动效。

Sprint 1 首页以「今晚，让世界慢一点。」为主标题，先呈现开始放松，再呈现四种今晚状态、三种场景、日记入口。页面动效仅一次性进入和短暂交互反馈，不循环；卡片悬浮仅在支持 hover 的精细指针上启用。

| ----------------- | ---------------------------------------------------- |
| 页面背景          | 深夜蓝 `#0c1120`，月光紫 `#151323`                   |
| 主文字            | 深夜蓝 `#e8e9f3`，月光紫 `#efeaf6`                   |
| 次级文字          | 深夜蓝 `#aeb5ca`，月光紫 `#b9b1cc`                   |

| 焦点描边          | 当前 `--accent`，2px，外偏移 5px                     |
| 分隔线            | 白色约 7% 透明度，仅用于装饰边界                     |

正文通常 13–15px，移动端保留行距；小号字仅用于英文分类、阶段与辅助元信息，不承载关键错误或主操作。主次文字与背景需在后续新增场景继续核查对比度，不以装饰分隔线承担唯一信息。

## 组件与响应式

- 主按钮为月光浅色实底，次按钮为深色边框，链接有真实目标；场景卡片可打开详情，明确「视觉预览」「音频待开放」，不制作假播放按钮。
- 语义结构为 header/nav/main/footer；每页单一 h1，章节 h2，卡片 h3。图标装饰时 `aria-hidden`，仅图标操作须有可访问名称。
- 760px 以下为单列场景，导航换行；1050px 以下调整间距、状态项为两列。验收尺寸为 375/768/1440px，最低布局宽度 320px，不依赖横向滚动。
- 按钮最小高 46px，主要链接提供足够触屏区域；支持 Tab、Enter、跳过导航与路由后主标题焦点管理。
- 状态提示使用 `role="status"`；检查中禁用重复请求，失败后可重试。
- 支持 `prefers-reduced-motion`，所有状态不能只靠颜色或动画表达；未来动画需按用户偏好关闭。

- 今晚状态使用原生 radio，支持 Tab、方向键和触屏，选中有圆点及文字建议，不只用颜色。
- 设置采用原生 `dialog.showModal()`，背景不可交互；Escape、关闭、完成和点击外侧均可关闭，返回原触发按钮，解除滚动锁。面板内部有独立滚动区域适应矮屏。
- 减少动画为 checkbox/switch；系统减少动态效果始终优先。夜景开关实际移除首页背景并隐藏场景装饰，保留语义文字和静态底色。
- 配色、夜景和减少动画只在当前浏览器持久化，存储失败明确提示；今晚状态与所选场景刷新重置。

## 文案与后续体验

优先「可以」「随时结束」「慢慢开始」等自主选择表达，不使用「睡眠不达标」「必须完成」「保证入睡」。今晚状态提供一般性建议，环境音可真实操作；日记入口有明确未开放说明，记录控件待真正实现后加入。

播放器需有明确主停止键、每轨标签与音量数值、键盘可调范围控件和异常提示。放松引导不强制跟随呼吸节奏，不通过声音突然提示结束。

## Sprint 2 播放器

播放器沿用现有 page/surface/text/accent/radius token 和月光紫按钮，独立样式位于 styles/audio.css。三轨桌面并列、900px 以下纵向排列；不引入跳动波形、分析数据或循环动效。range 有明确标签、0–100 值与键盘操作；开关点击区域不少于 44px。

场景标签改为 CC0 实录，状态严格区分准备/播放/暂停/收声/错误。播放状态以 role=status 提示，剩余时间关闭逐秒播报；失败用非模态提示且允许重试。总音量为零时明确显示。跨页控制条提供暂停/继续/停止和返回混音台的真实链接。

本轮不再把可用环境音标为“待开放”；日记、账户和引导仍按真实状态说明。原有减少动态效果的全局规则继续覆盖新控件。静态插画仅装饰，不伪称真实频谱。全局播放条出现时为页脚留出空间，长场景名称截断显示但保留完整可访问文本，避免遮挡隐私入口。
