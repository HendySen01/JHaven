# 项目状态

## 1. 项目基本信息

- JHaven，Your Quiet Haven, Every Night.
- 当前版本 0.1.0-alpha.7，Sprint 10.2 切换 PostgreSQL 运行层。聊天历史上线前须应用 PostgreSQL 007 并更新运行权限。
- 最近更新时间 2026-11-25（Asia/Macau）。当前分支 main 跟踪 origin/main。

## 2. 已完成功能

- 沉浸首页、场景、晚上状态建议、设置、界面偏好和基础 API。
- 公开声音库 16 条。咀嚼和风扇使用已登记的 CC0 实录。维护者确认酥脆咀嚼、口腔 ASMR、积木和落叶脚步可公开分发，四条已收入正式构建，沿用原 ID 和导出。
- 风扇单轨在相同滑块设定下约提升 8.1 dB。试听期间可实时调节当前轨道的音量，并保留混音配置。旧预设与收藏继续沿用现有 ID。
- 场景启动保留手调配比，试听使用所选轨的已设音量并隔离主混音，场景、卡片、全局栏显示统一引擎状态。
- DeepSeek 和 OpenAI 适配器复用统一行为提示与服务端校验。选定且授权后发送本次消息及最多六轮同供应商和模型的已完成对话，附发言日期。复杂输入获得更高推理与表达预算。OpenAI 配置需经独立验收后启用。
- 助手支持桌面 Enter 发送、Shift + Enter 换行和组合输入保护。触屏用按钮发送。请求失败保留草稿，成功后只清除本次提交文本。
- 受限时输入框旁显示原因及适用的恢复条件，草稿仍可编辑。站内恢复自动解锁，用户决定何时发送。切换本地知识时保留对话和草稿。
- 当前标签页可浏览完整对话，站内返回保留对话和草稿，未保存内容刷新后清除，换账号及清空当前对话会清理前端状态。登录后可手动或主动开启自动保存，从账户历史恢复。读旧消息时不强制跟随，提供回到底部入口。
- 可在本地知识模式回答睡梦问题并查看原始研究。AI 授权仍按接收方与模型绑定，开启前说明发送范围，消息来源按需展开。
- 声音搜索、分类、收藏、12 秒独立试听、混音/独立音量、静音、预设、定时渐弱、失败重试与证据页。原三轨存储可继续读取。
- B 阶段用户名注册、登录、退出撤销、刷新恢复、登录校验与保护路由。受保护账户接口只读取会话绑定的当前用户。
- PostgreSQL 参数化查询、用户名唯一、scrypt、会话期限、Cookie、Origin 校验、登录与注册限流、账户就绪 503。
- 个人声音场景 CRUD、设备收藏显式导入、默认播放设置。私人睡眠日记 CRUD、日期查询和 7/30 天趋势已实现。业务验证在隔离库进行。
- 成年访客与登录用户可使用思绪整理、身体觉察、温和呼吸和简短放松。支持规则理由、暂停、继续、跳过、结束、静音和可选本机语音。登录用户可明确选择保存练习，并在账户页删除记录。
- 睡前助手支持来源检索、停止、重新生成、重试和确认后执行的站内推荐。模型输出完整校验后分段发送。访客和登录用户都可使用本地知识或单独授权已开放的供应商。
- 375/768/1440px 主导航及跨页播放器布局已优化。助手推荐取消、日记编辑和收藏编辑有明确键盘焦点，音频中断和本机中文语音有可恢复状态。
- 日记查询显示范围与数量。7 天用时间条比较作息，30 天用日期格查看估计时长和醒来感觉，触摸、悬停或聚焦可看具体日期。时长按 UTC 经过时间计算，缺失字段保留原样。助手有实际引用才显示「参考资料」，本地回退和失败直接标记。

## 4. 重要技术决策

- Vercel Services 在同域将 `/api` 路由到 Express，其余路由进 Vite 静态服务。浏览器沿用相对路径与现有 Origin 校验。Express 入口是 `apps/server/app.ts`，只预先构建共享包，由 Vercel 按 `"type": "module"` 编译为 ESM。 [部署说明](DEPLOYMENT.md)
- 原件与本地优化版本保留，正式 16 条 WAV 由 Vite 静态构建打包，旧试听入口已移除。四条新增的许可记录仅写维护者确认及未提供的字段。
- 聊天使用内存 Pinia store，从最近 16 条同接收方记录优先取四轮近期对话和两轮主题相关历史，合计限 9,600 字节。允许附发言日期。其余内容仍可在界面查看。可选择将聊天保存到 JHaven 数据库，读写历史不调用模型。 [助手说明](ASSISTANT.md)
- Sprint 9 使用固定 HTTPS 白名单、禁止重定向、模型绑定授权和独立供应商额度，保留总量上限。Sprint 9.3 分开账户、访客、网络和本地模式的计数，并按供应商上报用量结算预留。继续复用 Node Fetch 和 Vue 原生交互，LeiBox Skill 已查询，远程索引不可达。无新增 npm 依赖。 [助手架构](ASSISTANT.md)
- 短 WAV 静态自托管。构建比对目录、许可、哈希和 PCM 质量。沿用单一惰性 AudioContext，按需加载、原生循环、独立增益、单调计时。混音增益按目录上限预留数字余量。
- 新默认总音量 45%。原设备音量仍保留。定时表单默认建议 20 分钟，用户显式应用，刷新和退出页面不会恢复播放。
- 用户名小写唯一。密码使用 Node scrypt 与独立随机盐；PostgreSQL 存随机令牌的 SHA-256 会话摘要。固定 7 天到期，退出及轮换即时撤销。
- 生产 Cookie 使用 Secure、HttpOnly、SameSite=Lax 与 __Host 前缀。写请求要求精确 Origin 和 JSON。基础健康与账户就绪分开。
- PostgreSQL 使用事务锁、独立迁移连接、SHA-256 历史、私有 `jhaven` schema 和最小权限角色。使用 `pg` 参数化查询，Vercel 每热实例最多一个 PostgreSQL 连接。旧 MySQL SQL 和登记历史保留，旧库数据搬运待单独安排。 [数据库说明](DATABASE.md)
- Sprint 4 以会话身份约束全部写入与查询，跨账号请求统一隐藏资源，场景同名冲突拒绝覆盖。日记所属日期和记录时区保留，事件时间使用 UTC；图表按当地时间保留跨日偏移与缺口。
- 账户默认设置只保留在当前账户的内存状态，退出或切换账户时清理并恢复设备混音。已有播放时不自动套用新登录账户的默认值。
- Sprint 3 引入 mysql2 3.24.6（MIT）。Sprint 4 评估了 Moodist、ECharts、LeiBox 与 Impeccable，沿用现有 Vue 组件并使用原生 SVG 绘制趋势。未新增 npm 依赖，未安装或使用额外 Skills。
- Sprint 5 使用确定性规则，保存的声音偏好优先覆盖规则声景，睡前状态仍决定练习类型。推荐不读取日记、不上传状态。复用全局音频引擎和原有定时渐弱，练习专用混音结束后恢复原配置。可选语音仅使用 Web Speech API 本机中文声线。沿用现有组件与项目样式，未新增第三方组件、依赖或 Skills。
- Sprint 6 使用独立助手路由、版本化审核知识和确定性站内动作。第三方模型只选择审核表达。服务不接入账户数据，不持久化聊天。评估 Vercel AI SDK，采用 Node 原生 Fetch，未引入第三方包或 Skills。 [助手配置与边界](ASSISTANT.md)
- Sprint 7 延用单一 Context、原生媒体和现有夜间组件。用 LeiBox Skill 检索 Vue 反馈控件，评估 Impeccable 的公开说明，未集成组件或新增依赖。 [第三方资源](THIRD_PARTY.md)
- Sprint 8 保持 AI 上下文授权范围和单一音频引擎。尝试使用 LeiBox Skill 检索聊天输入，远程索引不可达，复用现有 Vue 控件。两条 Freesound 风扇录音只作为待听审候选。无新增 npm 依赖。 [第三方资源](THIRD_PARTY.md)
