## 4. 重要技术决策

- 沿用 Node 24/npm 11、Vue 3/Router 4/Pinia 3、Tailwind、Lucide、Express/Zod；本轮不新增第三方依赖。
- 用 Vue 组件、原生 radio/switch 与 `dialog` 独立实现交互，避免额外动效运行时；原生模态隔离背景并支持 Escape，组件补充首尾 Tab 循环、焦点返回与页面滚动恢复。
- `evening` store 仅内存保存今晚状态和所选场景，规则建议是可单测纯函数，不上传或跨刷新保留。
- `preferences` store 仅把版本化的配色、减少动画和显示夜景写入 localStorage 键 `jhaven.ui-preferences.v1`。读取校验/白名单过滤，写失败只在本次访问生效并提示；无日记、身份令牌或账户数据。
- 系统 `prefers-reduced-motion` 始终优先；手动设置可进一步减少动画。配色通过根元素 token 切换，不引入远程字体、图片或音频。
- LeiBox 导航候选支持 Vue，但需要 GSAP、完整授权未确认；独立实现。Moodist 仅研究页面/组件组织，未复制源码和素材。详见 `THIRD_PARTY.md`。
