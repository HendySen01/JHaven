## 2. 已完成功能

- 沉浸首页、场景、晚上状态建议、设置、界面偏好和基础 API。

- B 阶段用户名注册、登录、退出撤销、刷新恢复、登录校验与保护路由。受保护账户接口只读取会话绑定的当前用户。
- MySQL 迁移与参数化查询、用户名唯一、scrypt、会话期限、Cookie、Origin 校验、登录与注册限流、账户就绪 503。
- 个人声音场景 CRUD、设备收藏显式导入、默认播放设置。私人睡眠日记 CRUD、日期查询和 7/30 天趋势已实现。业务验证在隔离库进行。
- 成年访客与登录用户可使用思绪整理、身体觉察、温和呼吸和简短放松。支持规则理由、暂停、继续、跳过、结束、静音和可选本机语音。登录用户可明确选择保存练习，并在账户页删除记录。
- 睡前助手支持来源检索、流式回复、停止、重新生成、重试和明确确认的站内推荐。无密钥使用本地审核知识，OpenAI 措辞可由管理员配置并由访客或登录用户单独同意。

## 4. 重要技术决策

- 短 WAV 静态自托管。构建比对目录、许可、哈希和 PCM 质量。沿用单一惰性 AudioContext，按需加载、原生循环、独立增益、单调计时。混音增益按目录上限预留数字余量。
- 新默认总音量 45%。原设备音量仍保留。定时表单默认建议 20 分钟，用户显式应用，刷新和退出页面不会恢复播放。
- 用户名小写唯一。密码使用 Node scrypt 与独立随机盐；MySQL 仅存随机令牌的 SHA-256 会话摘要。固定 7 天到期，退出及轮换即时撤销。
- 生产 Cookie 使用 Secure、HttpOnly、SameSite=Lax 与 __Host 前缀。写请求要求精确 Origin 和 JSON。基础健康与账户就绪分开。
- MySQL SQL 迁移含用户名、会话外键、过期索引与校验和记录，显式执行，UTC。真实测试实例为 MySQL 9.6.0。
- Sprint 4 以会话身份约束全部写入与查询，跨账号请求统一隐藏资源，场景同名冲突拒绝覆盖。日记所属日期和记录时区保留，事件时间使用 UTC；图表按当地时间保留跨日偏移与缺口。
- 账户默认设置只保留在当前账户的内存状态，退出或切换账户时清理并恢复设备混音。已有播放时不自动套用新登录账户的默认值。
- Sprint 3 引入 mysql2 3.24.6（MIT）。Sprint 4 评估了 Moodist、ECharts、LeiBox 与 Impeccable，沿用现有 Vue 组件并使用原生 SVG 绘制趋势。未新增 npm 依赖，未安装或使用额外 Skills。
- Sprint 5 使用确定性规则，保存的声音偏好优先覆盖规则声景，睡前状态仍决定练习类型。推荐不读取日记、不上传状态。复用全局音频引擎和原有定时渐弱，练习专用混音结束后恢复原配置。可选语音仅使用 Web Speech API 本机中文声线。沿用现有组件与项目样式，未新增第三方组件、依赖或 Skills。
- Sprint 6 使用独立助手路由、版本化审核知识和确定性站内动作。第三方模型只选择审核表达。服务不接入账户数据，不持久化聊天。评估 Vercel AI SDK，采用 Node 原生 Fetch，未引入第三方包或 Skills。 [助手配置与边界](ASSISTANT.md)
