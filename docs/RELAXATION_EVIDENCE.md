# 放松练习的依据与边界

2026-11-18 已核对指南、官方健康资料及原始论文。以下内容通过项目资料审核，可作为面向成年人的一般放松提示。JHaven 的具体文案、时长及推荐组合尚无临床验证，未取得独立临床审核。

| 练习     | 来源与研究对象                                                                                        | 依据、局限与审核结论                                                                                                                                    |
| -------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 思绪整理 | Scullin 等，2018。57 位 18–30 岁健康成年人，在实验室进行单夜比较，睡前写 5 分钟未来待办或已完成事项。 | 待办组比已完成事项组更快入睡。样本小、时间短、没有无写作对照。本应用改为可选的纸笔或心中整理，未验证这种改编的睡眠效果。可作为普通待办整理活动上线。    |
| 身体觉察 | Ong 等，2014。54 位成人慢性失眠受试者，比较两种多周正念干预和自我监测。研究活动含身体扫描等多种练习。 | 研究的一些自报指标改善，不能分离身体扫描这一步的贡献。短时接触觉察允许睁眼或把注意转到房间物品。可作为一般放松活动上线。                                |
| 温和呼吸 | NIH/NCCIH 放松技术资料，面向公众。AASM 2021 成人慢性失眠指南仅为临床放松疗法提供范围背景。            | NCCIH 将呼吸练习列为放松技术，AASM 的条件性推荐基于五项低质量研究。应用只提示自然呼吸，不指定节拍、深度或屏息。可作为一般放松活动上线，不推断治疗价值。 |
| 简短放松 | NIH/NHLBI 的健康睡眠习惯建议和 NIH/NCCIH 的放松技术资料。                                             | 官方资料支持在睡前安排放松时间。本短练习未采用临床肌肉紧张—放松、睡眠限制或固定离床时间。可作为一般睡前休息活动上线。                                   |

## 适用与隐私

- 适用成年人，包括可自行选择舒适姿势的年长成人。没有儿童或青少年专版；未成年人应使用适龄指导。禁止驾驶时使用。无需闭眼或强迫维持姿势。
- NCCIH 指出有少数人会感到更焦虑、出现侵入性思绪或不适。任何一步都可跳过和退出；头晕、气短或其他不适时停止。持续的睡眠问题可寻求合格专业人员。
- 状态选择只保留在浏览器内存。确定性规则从不访问睡眠日记。练习可静音，本机中文语音默认关闭且只读固定引导文案。没有合适的本机声线时显示文字。
- 仅用户点击保存时发送练习类型、经过秒数、完成状态和防止重试重复入库的随机标识。服务端另外记录保存时间。练习完成只表示流程结束，不推断睡眠改善或统计连续打卡。
