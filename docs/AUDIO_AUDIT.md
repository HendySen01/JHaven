# 音轨审计（2026-11-20）

工作区有 10 条原有音轨和 2 条实验性合成音。七条实录的作者、源页面和逐条 CC0 许可已复核，允许复制、修改和商用分发。五条合成音为 JHaven 原创。完整的作者、链接、来源及 SHA-256 见 [素材清单](AUDIO_ASSETS.md) 和静态 manifest。所有项目音轨均为 32 kHz、16 bit、单声道 WAV。

下表来自本轮 `npm run audio:verify`。峰值和首尾样本差为满刻度比例，瞬升是相邻 50 ms 窗口的最大电平上升。全部素材均无低于 −55 dBFS 的整窗静音，DC 和相邻样本跳变通过仓库阈值。保留建议基于可核验的来源和数字质量，实际内容匹配、噪声感、接缝听感及夜间适合度仍需人工试听。

## 待用户试听的真实录音

- **闭嘴嚼饼干**，Rudmer_Rotteveel，CC0，3.107 秒，44.1 kHz／16 bit／立体声 WAV。原页面确认是闭嘴实录。单段过短，饼干齿击可能偏脆，适合判断真实口腔声，循环和柔和度未验收。 [原页播放](https://freesound.org/people/Rudmer_Rotteveel/sounds/364924/)
- **Chewing Cookies**，DSPena，CC0，14.465 秒，44.1 kHz／16 bit／立体声 WAV。原描述先闭嘴后张嘴，可试听前半段，需判断口腔噪声和剪辑点。 [原页播放](https://freesound.org/people/DSPena/sounds/241951/)
- **Chewing_Ice Cream 2_Raw**，CAT-FOX_ALEX，CC0，72.468 秒，44.1 kHz／32 bit／立体声 WAV。原描述为 Xvive 1-R 实录，长片段更有利于自然变化。含脆响标签，实际响度与舒适度待试听。 [原页播放](https://freesound.org/people/CAT-FOX_ALEX/sounds/873422/)

## Crispy Squishy

检索 Freesound 及公开素材索引中的 crispy squishy、wax cracking、wax-coated squishy。找到类型参考，尚未找到同时能核实真蜡薄壳挤裂、连续自然碎裂和碎片摩擦，且许可允许集成的独立录音。候选采纳门槛为三段声纹均可由人工试听辨识、峰值可温和整形、片段足够长或可自然编排。普通软玩具、Pop It、湿挤压和电子模拟均排除。

可在原平台试听两条参考。公开介绍支持其蜡壳类型，原始音频格式及可再分发授权未获确认。项目没有提取视频音轨，也没有将合成音当作真实蜡壳素材替换。 [Kitty 参考](https://www.youtube.com/watch?v=bCfgZDXtm20) [Vito ASMR 参考](https://www.youtube.com/watch?v=goBo1Ps8GjY)
