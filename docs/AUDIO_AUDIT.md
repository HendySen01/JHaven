### 手动提供原件并生成试听件

1. 在以上原页登录，使用 Freesound 的原始下载入口。把两条 WAV 分别保存为忽略提交的 `artifacts/sprint9-audio/soft-chew.original.wav` 与 `artifacts/sprint9-audio/fan.original.wav`。
2. 试听原件，确定 11–31 秒的整秒长度片段。运行 `node scripts/prepare-approved-audio.mjs fan <起始秒> <结束秒>` 或把 `fan` 换成 `soft-chew`。脚本只读原件，在相同目录生成 32 kHz PCM WAV 与单轨 manifest 记录。需使用系统 Chrome 时设置 `PLAYWRIGHT_CHANNEL=chrome`。
3. 听两圈试听件，确认接缝、环境杂音和瞬态。正式替换保留既有 ID，更新对应 WAV、manifest、`ATTRIBUTION.txt`、目录名称及合成说明，再执行 `npm run audio:verify` 与浏览器的单轨试听、正式混音和收藏回归。两份原文件与试听中间件不进入 Git。

## Sprint 8 复查

- 对照 Sprint 7 基线 `a82a205`、后续版本 `2952981` 与本轮目录。原有 10 个 ID 全部延续。后两个实验轨在后续版本进入正式目录，本轮没有删除、替换或重新编码任何 WAV。试听和混音都由单一引擎按 `/audio/<ID>.wav` 加载。
- `fan` 由固定种子滤波噪声、83 Hz 基频与二次谐波合成。本轮标记为「柔和风扇声（合成）」。原文件和用户设定继续使用同一 ID。
- `soft-chew` 与 `gentle-crinkle` 是滤波噪声和造型脉冲包络。前者的旧名称因准确标注素材而变化，卡片仍在「轻柔拟音」分类。本轮恢复旧名、咀嚼和 Crispy Squishy 等关键词搜索，明确说明当前声音类型，保留收藏、预设和音量映射。
- 两条实验轨均缺少真实材料或口腔录音。现有数字指标见下表，无法据此确认听感。本轮未替换三条音轨。

## Crispy Squishy

检索 Freesound 及公开素材索引中的 crispy squishy、wax cracking、wax-coated squishy。找到类型参考，尚未找到同时能核实真蜡薄壳挤裂、连续自然碎裂和碎片摩擦，且许可允许集成的独立录音。候选采纳门槛为三段声纹均可由人工试听辨识、峰值可温和整形、片段足够长或可自然编排。普通软玩具、Pop It、湿挤压和电子模拟均排除。
