# 变更记录

## 0.1.0-alpha.1 — 2026-11-18

- 首页更新为「今晚，让世界慢一点。」，新增品牌/导航/主操作/背景/场景/状态/设置组件。
- 四种今晚状态实时显示规则建议，状态和场景仅存内存。
- 增加 `/relax`、三种场景详情、无效场景回退与 `/journal` 未开放说明；不模拟播放或保存。
- 设置支持原生模态、键盘关闭与焦点返回；配色、夜景和减少动画仅存版本化 localStorage，处理损坏与受限存储。
- 创建 PROJECT_STATUS，补充 AGENTS 的跨会话与收尾规则，同步产品/架构/设计/安全/路线/第三方/测试/提交说明。
- 版本与工作区锁文件同步，未新增第三方依赖；E2E 扩展到 375/768/1440px。
- 真实音频、认证、数据库、日记 CRUD 和 AI 仍未实现。测试结果见 `TESTING.md`。

## 0.1.0-alpha.0 — 2026-11-18

### 新增

- npm workspaces：Vue 前端、Express 服务、共享契约。
- 宁静夜间风格首页、阶段说明、隐私边界、404 与真实服务检查/重试。
- TypeScript 严格模式、Tailwind Vite 插件、Router、Pinia 和 Lucide。
- 环境校验、安全头、请求编号、JSON 大小限制与统一错误。
- Vitest/API 与 Playwright 桌面、移动流程；格式、Lint、类型与构建命令。
- 工程约定及产品、架构、设计、安全、数据库草案、第三方、测试、部署和后续路线文档。

### 技术选择与限制

- 使用 Lucide 维护者指定的 `@lucide/vue`，替代已弃用的 `lucide-vue-next`。
- 已检索 LeiBox，因选定条目的完整授权未能确认而独立实现基础界面。
- 本阶段没有实现音频、数据库迁移、认证、日记、推荐、放松引导或 AI。
- 未 commit、push 或部署生产环境。执行结果见 `TESTING.md`。
