# 变更记录

## 0.1.0-alpha.5 — 2026-11-18

- 账户声音预设可创建、导入、编辑、使用和删除。场景名冲突保留原记录并提示改名。
- 持久化默认场景、总音量及定时。访客继续使用设备预设，账号切换时清理账户数据。
- 私人日记保存可选作息、休息感和备注，支持明确时区、跨午夜、日期查询和 7/30 天真实趋势。
- 新增隔离库迁移、个人数据访问控制和浏览器验证。正式 MySQL 须由管理员执行增量 SQL。

## 0.1.0-alpha.4 — 2026-11-18

- 新增用户名注册、登录、会话检查、退出及受保护账户 API 和 Vue 页面。
- MySQL 迁移记录、用户唯一约束、会话摘要与过期索引。scrypt、HttpOnly Cookie、生产 HTTPS、同源 CSRF 检查与限流。
- 访客可以使用声音库，设备收藏和预设继续留在设备。增加真实 MySQL 双账户隔离、会话过期与浏览器端到端验证。

## 0.1.0-alpha.3 — 2026-11-18

- 审核 13 个候选，新加入 4 条 CC0 实录及 3 条自制背景音，重整原细雨峰值。
- 新增分类、搜索、收藏、12 秒单独试听、完全静音、证据页与两套预设。兼容原三轨本地配置。
- 生产构建校验素材清单和数字质量。降低默认音量并按目录规模预留混音余量。

## 0.1.0-alpha.2 — 2026-11-18

- 新增单一 Context 的 Web Audio 引擎、三轨原生循环、独立/总音量、暂停/继续/短渐弱停止、全局跨页控制与资源清理。
- 引入三条原页面逐项核查 CC0 的雨/海浪/风实录，剪辑为紧凑循环 WAV；附制作、校验工具、作者、来源和 SHA-256。
- 三种内置预设、平滑混音、最多 20 个本地自定义场景与配置恢复；刷新不自动播放或恢复计时。
- 单调计时、不定时/10/20/30/自定义分钟、暂停/恢复/取消/重设、音频线程渐弱与旧任务取消。
- 处理并发、迟到解码、浏览器挂起、权限拒绝、加载/解码错误及超时；真实浏览器发现并修复原生 fetch 接收者问题。
- 修复浏览详情重置混音、自定义场景名称恢复与移动端全局播放条遮挡隐私入口；回归测试等待 SPA 导航完成后再返回。
- 扩展受控与真实 Chrome/Edge 音频测试，不以 Mock 替代浏览器采样；保留原设计、键盘和减少动态效果。
- 未新增 npm 依赖；版本/锁文件与文档同步，未执行 commit/push/生产部署。

## 0.1.0-alpha.1 — 2026-11-18

- 首页更新为「今晚，让世界慢一点。」，新增品牌/导航/主操作/背景/场景/状态/设置组件。
- 四种今晚状态实时显示规则建议，状态和场景仅存内存。
- 增加 `/relax`、三种场景详情、无效场景回退与 `/journal` 未开放说明；不模拟播放或保存。
- 设置支持原生模态、键盘关闭与焦点返回；配色、夜景和减少动画仅存版本化 localStorage，处理损坏与受限存储。
- 创建 PROJECT_STATUS，补充 AGENTS 的跨会话与收尾规则，同步产品/架构/设计/安全/路线/第三方/测试/提交说明。
- 版本与工作区锁文件同步，未新增第三方依赖；E2E 扩展到 375/768/1440px。
- 真实音频、认证、数据库、日记 CRUD 和 AI 仍未实现。测试结果见 `TESTING.md`。
