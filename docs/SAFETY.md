# 安全、隐私与内容边界

## 当前真实能力

初始化阶段有公开页面、本地混音播放器和只读健康接口。服务默认本机监听，环境示例不含真实密钥。以下按阶段记录存储和账户边界。

Sprint 1 仅在 localStorage 的 `jhaven.ui-preferences.v1` 中保存配色、减少动画与夜景显示及格式版本；不含今晚状态、场景、身份令牌、日记或账户信息。今晚状态与所选场景只存内存，刷新清空，不上传。存储数据视为不可信输入，校验并只选取允许字段；读取异常回退默认、写失败告知只在本次生效。

Sprint 2 另使用 `jhaven.audio.v1`，只保存三个白名单音轨的启用/音量、总音量、已选场景 ID 和用户命名的自定义配比（最多 20 个）。严格校验版本、类型、长度、范围与重复 ID，不接受远程音频 URL；不保存身份令牌、播放状态、计时截止点或日记。场景名仅在本浏览器保存，Vue 文本插值显示，不作为 HTML 渲染。刷新后不自动播放；保留配置与正在播放是不同状态。

Web Audio 由用户手势启动，加载/解码/权限失败不得显示 playing；Context 被系统挂起时进入暂停，用户主动继续才重新发声。pagehide/根卸载清理节点、请求、监听与上下文。定时仅用于放松辅助，不能依赖手机锁屏或后台持续运行；提示已在播放器显示。音量参数不代表硬件声压安全保证，不宣称医学作用。

已实现：启动环境校验、有限 JSON 正文、严格健康查询参数、安全响应头、服务端请求编号、统一错误与前端超时/错误恢复。不信任客户端可控的请求编号，不输出私人请求正文或原始异常堆栈。

## 开放私人业务前的必要条件

- 密码使用经评估的 Argon2id 或合适参数的 scrypt 等安全哈希和随机盐，不自造加密算法，不存明文密码。
- 优先采用服务端可撤销的会话与 HttpOnly、Secure、SameSite Cookie；本地开发仅在明确配置下允许非 Secure。生产要求 HTTPS，不将令牌写入 localStorage。
- 对写操作校验精确 Origin 并使用会话绑定 CSRF token；不得仅依赖 CORS。跨域如确有需要，使用明确白名单，不允许携带凭据时通配来源。
- 登录、注册和敏感写接口限流，统一登录失败提示，处理 Cookie 生命周期、登出撤销和密钥轮换。未选择认证方案前不创建半成品登录接口。
- 服务端校验类型、长度、范围、枚举和所有权；所有 SQL 参数化。跨用户访问、未登录写入、CSRF、SQL 注入与 XSS 要有有效测试。
- 私人响应不缓存；不把日记渲染为未经净化的 HTML。日志不含密码、令牌、Cookie、正文或 SQL 参数中的私人内容。
- 提供记录与账号删除，明确备份保留和恢复策略，配置最小权限数据库用户、发布密钥与备份访问权限。

## 产品与内容

JHaven 不是医疗诊断或治疗软件。任何页面、推荐规则或 AI 都不得诊断疾病、承诺临床疗效、保证快速入睡或编造研究与用户反馈。

初始化文案只表达普通休息意愿，没有临床建议。后续知识内容需附可核验来源、审核状态和版本；没有可靠来源时不发布效果性主张。身体扫描、思绪整理等内容须说明可选、可暂停和随时退出，不实施复杂临床流程。

用户音频必须由手势启动，失败不能显示播放中；考虑浏览器暂停、后台节流、系统锁屏、音量变化与设备差异。定时停止不能承诺后台毫秒精度。停止、切场景、离开页面与异常时有资源释放策略。

## AI 与第三方

Alpha 不接入真实 AI，也不安装 AI SDK 占位。后续发送任何私人内容前，必须独立展示发送字段、用途、供应商和可撤回选择，获得明确授权；拒绝授权仍应能使用非 AI 核心功能。不能用宽泛隐私条款代替逐项授权。

第三方代码及素材逐项核验许可与脚本行为，详见 `THIRD_PARTY.md`。不加载来源不明的远程脚本，不为参考组件执行未知安装脚本。npm audit 仅反映已知公告，不能代表完成安全审计。

## 声音用途

自然实录和自制背景音为可选的环境声音。按个人感受从舒适的低设备音量开始，使用静音、停止或定时功能，保持对警报与重要提示的感知。研究边界见 [SOUND_EVIDENCE](SOUND_EVIDENCE.md)。

## Sprint 3 账户

注册只收集用户名和密码，服务端保存盐及密码哈希。Cookie、会话摘要、用户名和密码不进入业务日志。身份由服务端会话确认，写请求有明确来源校验。设备声音偏好和账户数据分开。 [账户安全细节](AUTH.md)

## Sprint 4 私人数据

日记备注及账户偏好存于 MySQL，浏览器的私人视图数据只留在内存，响应禁止缓存。仅本人可查询、修改及逐条删除。使用文本插值显示备注，避免记录敏感正文、SQL 参数或令牌。本任务在隔离库验证这些行为，正式库上线及邀请前仍需完成账户级删除和备份恢复治理。 [个人空间](PERSONAL_SPACE.md)
