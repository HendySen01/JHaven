# 声音用途与证据审核

2026-11-19 增补的两条原创拟音用于自愿试听和个人声音偏好。咀嚼与脆响可能令人不适，均保持默认关闭，没有相应的睡眠改善证据或个性化推荐规则。

审核日期为 2026-11-18。13 个候选中，7 条自然实录和 3 条稳定背景音进入普通声音库，3 个音乐候选暂缓。偏好、录音质量、素材权利和研究证据分别审核。对某个声音感到放松，不足以证明睡眠改善。

| 候选           | 类别 | 预期用途                 | 研究与证据结论              | 局限、注意事项与决定                               |
| -------------- | ---- | ------------------------ | --------------------------- | -------------------------------------------------- |
| 细雨           | 自然 | 轻柔背景                 | N，情绪与烦扰方面有间接证据 | 缺少具体录音的睡眠验证。旧素材重做峰值，纳入       |
| 窗边雨声       | 自然 | 听雨、背景陪伴           | N，同类间接证据             | 滴答偏好不同，整形后纳入                           |
| 轻柔海浪       | 自然 | 起伏的水声               | N，水声研究包括积极感受指标 | 无此素材的睡眠数据，可能对明显起伏敏感，纳入       |
| 远处潮汐       | 自然 | 较远的浪声               | N，同类间接证据             | 海浪动态有起伏，选取平稳段纳入                     |
| 微风           | 自然 | 混音底层                 | N，自然声整体证据           | 风声缺少单独睡眠验证，原始录音可含自然杂声，纳入   |
| 树叶沙沙声     | 自然 | 可选叶片纹理             | N，自然声整体证据           | 不能推广到任意森林音或鸟鸣，选取平稳段纳入         |
| 轻柔溪流       | 自然 | 水流背景                 | N，水声的感受指标           | 此录音未有睡眠效应数据，纳入                       |
| 粉红噪音       | 稳定 | 让部分轻微环境杂音不突出 | S，成人研究结果不一致       | 持续噪音不同于脑电同步刺激，不宣传深睡，普通选项   |
| 白噪音         | 稳定 | 可选背景                 | S，证据不强                 | 高频感可能偏亮，建议低音量，普通选项               |
| 柔和风扇声     | 稳定 | 连续低频背景             | S，作为连续背景的间接参考   | 未发现支持本仿真风扇音睡眠效果的直接证据，普通选项 |
| 柔和氛围音乐   | 音乐 | 睡前聆听                 | M，部分成人主观评分改善     | 具体曲目未完成授权、动态和结束方式审核，暂缓       |
| 舒缓钢琴       | 音乐 | 睡前聆听                 | M，同类证据                 | 需核查乐谱、录音及瞬态，暂缓                       |
| 轻柔无歌词音乐 | 音乐 | 睡前聆听                 | M，同类证据                 | 不同曲目与研究协议不可互换，暂缓                   |

- **N**：Buxton 等，2021 年，PNAS。核对 PubMed 摘要与图表说明。对参与自然声暴露研究的人群，18 项纳入元分析，观察情绪、认知、应激与烦扰等结局。水声在积极感受与健康指标上呈现较大平均效应。未从摘要推断各音源的睡眠因果或人群普适性。 [原文摘要与图表](https://pubmed.ncbi.nlm.nih.gov/33753555/)
- **S**：Capezuti 等，2022 年，JCSM。核对开放全文的方法、结果和讨论。34 项研究共 1,103 人，多在实验室或医院。白噪、粉红噪声和多音组合结果有分歧，设计、强度与测量异质，缺少强证据，短期不良事件未报告也不足以推断整夜安全。 [开放全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9163611/)
- **M**：Jespersen 等，2022 年，Cochrane。核对公开证据页及结构化摘要。13 项研究共 1,007 名有失眠症状的成人。主观 PSQI 评分改善为中等确定性，失眠严重程度和客观睡眠指标仍不确定，参与者无法对音乐干预设盲。未将结果外推到自然声或特定曲目。 [证据页](https://www.cochrane.org/evidence/CD010459_music-insomnia-adults)
- **临床边界**：Edinger 等，2021 年 AASM 指南面向慢性失眠成人。对多组分 CBT-I 给予强推荐，对专业放松治疗给予条件推荐。查看了开放指南的建议与适用范围，未将播放背景音当作临床干预。 [开放指南](https://pmc.ncbi.nlm.nih.gov/articles/PMC7853203/)

产品建议使用舒适低音量，保留对警报和重要提示的感知，允许静音、定时及随时停止。未设置频率治疗、掩盖警报或普遍改善睡眠的宣传语。雷暴、突发鸟鸣、强浪、尖锐虫鸣与明显动态音乐没有进入本次默认场景。
