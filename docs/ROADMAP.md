- [x] Vue/Vite/TypeScript/Router/Pinia/Tailwind/Lucide 基础。

## Sprint 1：沉浸式 UI、交互与状态管理（已完成）

- [x] 品牌、标语、欢迎语、真实导航与开始放松入口。
- [x] 今晚四种状态与可解释建议；状态只存内存。
- [x] 雨夜、海岸、微风的场景列表与视觉详情；明确无音频。
- [x] 日记说明入口，不接受私人记录或模拟保存。
- [x] 原生模态设置、减少动画、配色和夜景偏好；本地存储校验与错误提示。
- [x] 跨会话 PROJECT_STATUS 与 AGENTS 长期维护规则。
- [x] 最终检查与 375/768/1440px 浏览器验收归档：35 项单元/API、30 项 E2E、类型/Lint/构建通过。

## Sprint 2：环境音引擎（当前环境验收完成）

1. 已核查三条 Freesound CC0 实录并自托管；来源、作者、处理与哈希清单完整。
2. 已实现独立 Web Audio 引擎、手势启动、多轨/总音量、预设、暂停/继续/主动停止及资源释放。
3. 已实现本地自定义预设、损坏存储回退、不定时/10/20/30/自定义定时与可取消渐弱。
4. 最终 73 项单元/API、Chrome 51 项、Edge 7 项、类型/Lint/生产构建与素材校验通过；375/768/1440px 截图逐张复核，移动播放条遮挡已修复。结果与设备限制见状态文件和 TESTING。

完成条件：真实解码与播放图验证、错误/权限/并发/计时/渐弱测试、375/768/1440px UI 回归和完整构建通过。真机/锁屏/听感限制如实记录；不能以桌面仿真替代真机。

## Sprint 3：身份与私人日记基础

1. 确定会话方案，建立 MySQL 迁移、最小权限连接与备份恢复流程。
2. 实现注册/登录/登出、Cookie/CSRF/限流、安全密码哈希和服务端验证。
3. 实现日记增删改查、可选字段、本地日期与时区、有限分页和简单趋势。
4. 验证每类私人资源的跨用户隔离；本地声音预设已在 Sprint 2 完成，账户同步要另行授权和迁移。

完成条件：两个真实测试账户无法互访资源；能删记录与账号；恢复演练、隐私说明与错误场景通过。

## Alpha 3：温和引导与朋友内测

提供经过内容审核、可暂停/跳过/结束的非临床放松内容；按实际需求存必要会话信息。完善主入口、设备兼容性、键盘与触屏体验，再邀请少量朋友；不默认收集追踪数据。

完成条件：核心流程真实可用；没有高优先级隐私或数据隔离缺陷；文案边界清楚；部署、回滚、删除与反馈渠道明确。

## Beta

根据真实反馈修复稳定性、后台行为与易用性，完善知识来源、可访问性、备份、导出和用户自助管理。性能目标须基于可复现测量建立，不提前虚报指标。

## V1.0 与长期产品化

明确运维责任、数据保留周期、内容审核、依赖维护和发布流程。在核心功能稳定后，评估规则引擎 + 审核知识库 + AI；先设计授权与发送边界，再选择 SDK。AI 不成为非 AI 功能的强制前提。
