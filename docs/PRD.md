# 产品需求

## 定位

JHaven 为希望在夜晚减少干扰、进行低风险放松、回顾睡眠习惯的人提供一个宁静空间。品牌标语：Your Quiet Haven, Every Night. 中文含义：每一个夜晚，都有一处属于你的宁静港湾。

首个真实业务版本面向少量受邀朋友。产品不做医疗诊断、不承诺治疗、不保证快速入睡；避免睡眠分数、排名、连续打卡压力和恐吓式提示。

## 当前 Sprint 1 范围

在已完成的工程基础上，交付沉浸式首页、今晚四种状态与可解释建议、三种场景列表/详情、日记说明入口、设置面板及跨会话状态文档。首页欢迎语为「今晚，让世界慢一点。」，主操作「开始放松」进入场景选择。

状态与场景仅存内存；界面偏好可在浏览器本地持久化，明确展示存储边界和失败提示。当前没有真实音频、账户、数据库、日记 CRUD、放松计时器或 AI。场景为独立 CSS 视觉预览，不提供假播放或假保存按钮。日记入口明确记录功能未开放，不接受私人正文。

Sprint 1 验收：所有按钮和链接可操作；radio 与设置可用键盘和触屏；模态关闭和焦点恢复正确；尊重系统减少动态效果；375/768/1440px 无横向溢出；偏好损坏与存储受限可安全处理；类型、Lint、Vitest、构建与可用的浏览器测试有真实记录。

## 关键体验原则

- 尽快进入休息状态，不自动播放，不连续弹窗，不重复索取不必要的资料。
- 音量默认克制，任何时候可主动停止；不能保证浏览器后台仍持续播放或精确定时。
- 日记尽可能简单，不强制填写自由文本；未记录不视为失败。
- 尊重系统减少动态效果偏好，避免依赖 GPU 重动效、远程大图或强玻璃模糊。
- 错误必须可理解、可恢复；不将加载中、连接失败或未实现伪装为成功。

## 后续 AI 边界

Beta/V1.0 后才评估「规则引擎 + 审核知识库 + AI 语言交互」。用途限于选择放松场景、整理用户主动提供的思绪、解释已审核知识、总结用户明确提供的记录。禁止诊断、编造数据、承诺疗效、实施复杂临床干预、将相关性称为因果性；未经单独明确授权不得向第三方发送敏感内容。

## 反馈与发布

首次内测通过朋友的自愿反馈验证流程是否清楚、音频是否稳定、日记是否容易使用。不虚构留存率、性能或满意度；不因收集指标默认加入追踪 SDK。各阶段完成条件见 `ROADMAP.md`。
